```
n = int(input())
lst = list(map(int, input().split()))
B, C = map(int, input().split())

#교실의 개수 - 미리 지정하고 시작
cnt = n 

for i in lst:
    #총감독수 제외
    i -= B 

    if i>0: 
        if i%C:
            cnt += (i//C)+1
        else:
            cnt += (i//C)

print(cnt)
```
