# 10807 - 개수 세기

## 소개
이 문서는 Python을 사용하여 배열 내 특정 숫자의 개수를 세는 알고리즘에 대한 설명을 제공합니다. 주어진 문제는 배열에서 특정 숫자가 몇 번 등장하는지를 계산하는 것입니다. 이 문제는 배열을 다루는 기본적인 알고리즘을 연습하는 데 유용합니다.

## 구현 세부사항
주어진 문제를 해결하기 위해, 사용자는 다음과 같은 단계를 따릅니다:

1. 사용자로부터 배열의 크기와 배열의 요소를 입력받습니다.
2. 사용자가 찾고자 하는 숫자를 입력받습니다.
3. 배열 내에서 해당 숫자의 개수를 세고 출력합니다.

아래는 이 문제를 해결하기 위한 Python 코드입니다:

```python
# 배열 속 숫자 v가 몇개 포함되어있는지 알아보자 
# 배열은 최대 100개의 숫자

n = int(input())  # 배열의 크기 입력
arr = list(map(int, input().split()))  # 배열 요소 입력
v = int(input())  # 찾고자 하는 숫자 입력

# count=0
# for i in arr:
#     if v==i:
#         count += 1
print(arr.count(v))  # 배열 내에서 v의 개수 출력
```

이 코드는 `arr.count(v)` 메서드를 사용하여 배열 `arr`에서 숫자 `v`의 개수를 간단하게 세어 출력합니다. 이 방법은 Python의 내장 메서드를 활용하여 코드의 가독성을 높이고, 효율적으로 문제를 해결합니다.

## 주요 기능
- **입력 처리**: `input()` 함수를 사용하여 사용자로부터 데이터를 입력받습니다.
- **배열 생성**: `map()`과 `list()` 함수를 사용하여 입력된 숫자들을 배열로 변환합니다.
- **개수 세기**: `count()` 메서드를 사용하여 배열 내 특정 숫자의 개수를 세는 기능을 제공합니다.

## 사용 예제
다음은 이 알고리즘을 사용하는 예제입니다:

### 예제 1
```
입력:
5
1 1 2 3 1
1

출력:
3
```
위의 예제에서 배열 `[1, 1, 2, 3, 1]`에서 숫자 `1`은 총 3번 등장합니다.

### 예제 2
```
입력:
7
4 5 6 4 4 5 4
5

출력:
2
```
이 경우, 배열 `[4, 5, 6, 4, 4, 5, 4]`에서 숫자 `5`는 2번 등장합니다.

이 문서는 배열에서 특정 숫자의 개수를 세는 간단한 알고리즘을 설명하였으며, Python의 유용한 기능을 활용하여 효율적으로 문제를 해결하는 방법을 보여주었습니다.
